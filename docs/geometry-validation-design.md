# 図形成立チェックの設計メモ

## 目的

証明エンジンが命題を導けることと、入力された図形条件が平面上で同時に成立することを分離する。チェック結果をひとつの真偽値に押し込まず、次の段階を区別する。

1. **構造エラー**: 未宣言の点・直線・円、重複ID、不正な交点定義、退化した目標三角形など。
2. **構造的に整合**: 参照関係やデータ形状は一貫している。
3. **幾何学的成立は未検証**: 交点の一意性、条件同士の両立、動点の存在、弧の選択範囲など。
4. **幾何学的成立を検証済み**: 将来、数値・記号的な幾何ソルバーと境界条件の検査を追加した後にのみ使用する。

## 今回実装する範囲

`js/geometry-validator.js` は保守的な構造検証器として、点・オブジェクトIDの重複、参照先の存在、線分や角の点数、交点定義の対象が直線であること、目標三角形の頂点重複などを検査する。構造に問題がなければ `structurally-valid-geometry-review-pending` を返す。

交点が本当に一意に存在するか、円と直線が実際に交わるか、動点条件を満たす点が指定された弧にあるか、すべての条件が同時に成立するかは判定しない。これらは `pending` に理由付きで残す。したがって、この検証器だけを通過しても出題許可にはならない。

## 次の段階

- 点・直線・円・交点を共通の幾何モデルとして正規化する。
- 既知の位置関係から交点の順序や弧の向きを誤推定しないため、必要な位置条件を明示する。
- 円周上の点・交点・平行線について、数値座標による反例検出を追加する。
- 動点の存在は、パラメータ化した円周と条件式を使い、範囲内に解があるかを独立に検査する。
- 数値検査で通っただけの場合も、許容誤差や退化ケースを記録し、証明済みとは区別する。

## 出題ゲート案

`proof.success === true` かつ `geometry.status === "geometrically-validated"` の両方が揃った候補だけを自動出題対象にする。現状は後者を返す検証器がないため、安全側に倒して保留する。
