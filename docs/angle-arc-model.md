# 角・弧の座標モデル（初期段階）

## 目的

描画に使う座標候補について、角度、円周角、弧の測度を数値として評価し、弧の選択の曖昧さを暗黙に埋めないための基盤を用意する。実装は `js/angle-arc-model.js`。

## 扱うこと

- 点と中心から偏角を計算し、円周上の点を反時計回りに並べた巡回順序を得る。
- 3点で定まる角の小さい方の測度を計算する。
- `inscribed-angle` 条件で、円・弧の端点・`arcChoice` が明示された場合に、角の測度と弧の半分を比較する。
- `equal-arcs` 条件で、円・弧の選択が明示された場合に、弧の測度を比較する。

`arcChoice` は `minor`、`major`、`clockwise`、`counterclockwise`、または円周角条件に限り `through-point`（併せて `throughPoint`）を指定できる。既存データに選択情報がなければ、推測せず pending とする。

## ステータス

- `angle-arc-witness-invalid`: 実装した数値条件への違反を検出。
- `angle-arc-witness-partial`: 未対応または曖昧な条件が残る。
- `angle-arc-witness-consistent`: このモデルで検査対象になった条件を通過。

このモジュールは座標候補を探索せず、座標候補の存在も、すべての幾何条件の同時成立も、証明目標の一般的成立も保証しない。特に「円周角と弧」の関係は弧の選択を明示した数値検査であり、証明エンジンの証明の代わりにはならない。
