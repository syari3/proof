# 点の順序と角の言い換え

## 何を区別するか

- `angle(BAD)` と `angle(DAB)` は、同じ頂点Aと同じ2本の半直線を逆順で書いた表記なので、表記を正規化すると同じ角になる。
- `angle(BAD)` と `angle(CAD)` は、BとCがAから見て同じ向きの半直線上にあると確認できる場合に限って同じ角と扱う。
- 「A、B、Cが同一直線上」という情報だけでは、BとCがAから見て同じ向きか反対向きかは決まらない。

## データでの表し方

`between` は3点の順序を明示する。たとえば `{ "type": "between", "points": ["A", "B", "C"] }` はBがAとCの間にあることを意味する。

- この条件から `sameRay(A,B,C)` と `sameRay(C,B,A)`、および `oppositeRay(B,A,C)` を導く。
- `same-ray` は同じ向きの半直線を、`opposite-rays` は反対向きの半直線を直接指定する。
- 同じ頂点に2組の反対向きの半直線があれば、そこから対頂角の組を生成する。
- 交点の定義だけから、どの点が間にあるかは推測しない。

## 実装上の注意

角の表記正規化と、幾何条件に基づく角の同一性判定は別の処理である。前者は端点の順序を統一し、後者は明示された半直線の向きの事実を使う。点の位置関係が不足している場合は、推測して定理を適用せず、追加条件または未対応として扱う。
