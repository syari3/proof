- **汎用的な推論処理を追加し、個別テストもあるもの**: 12/19件（約63.2%）を暫定的に数える。二等辺三角形の底角、三角形の内角の和、同じ円の半径、明示された対頂角、三角形の外角定理、角の加法、線分の加法、等しい角に対する辺の等しさ、任意の頂点名に対応するAA相似、SSS合同、SAS合同、ASA合同。各ルールは必要な図形条件を明示した事実として入力する必要がある。
- **実行テストで確認できた対応**: 19/19件（100%）に関連する正例・負例テストがある。ただし、カタログIDと実行ルールIDが一致しない箇所があり、テストの入力形式も明示事実に限られるため、数学的な網羅検証が完了したという意味ではない。

## 件数の数え方に関する訂正
