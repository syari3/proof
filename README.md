# 証明問題メーカー

中学図形の証明を、理由と手順を確認しながら学ぶためのブラウザアプリです。

## 現在の状態

初期プロトタイプです。次のサンプルを切り替えて表示できます。

- 二等辺三角形の底角
- 平行線の錯角
- 三角形の相似条件（2組の角）
- 円周角（直径に対する円周角）

## 起動方法

```text
index.html をブラウザで開く
```

ビルドツールやサーバーは不要です。

## 公開方法

GitHub Pagesで公開する構成を想定しています。リポジトリの Settings → Pages で公開元を設定します。

## 大事な制約

- 現在表示するのは手作業で確認できるサンプルです。任意の問題を自動生成する証明エンジンはまだありません。
- 図は模式図です。図の形だけから数学的な条件を推測してはいけません。
- `ProofRules.prove(facts, goal)` は、登録済みルールを前向きに適用し、目標に到達したかと各推論ステップを返します。
- 証明探索にはステップ上限があります。登録済みルールで導けない結論は成功扱いしません。
- この仕組みは登録済みルールの範囲内で動く初期エンジンであり、一般的な幾何学の証明器ではありません。
- 今後の自動生成では、各ルールの前提条件をプログラムで確認し、導けない結論を証明として表示しない設計にします。
