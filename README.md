# 証明問題メーカー

中学図形の証明を、理由と手順を確認しながら学ぶためのブラウザアプリです。

## 現在の状態

初期プロトタイプです。次のサンプルを切り替えて表示できます。

- 二等辺三角形の底角
- 平行線の錯角
- 三角形の相似条件（2組の角）

## 起動方法

```text
index.html をブラウザで開く
```

ビルドツールやサーバーは不要です。

## 公開方法

GitHub Pagesで公開する構成を想定しています。リポジトリの Settings → Pages で公開元を設定します。

## 大事な制約

- 現在表示するのは手作業で確認できるサンプルです。任意の問題を自動生成する証明エンジンはまだありません。
- 図は模式図です。図の形だけから数学的な条件を推測してはいけません。
- 今後の自動生成では、各ルールの前提条件をプログラムで確認し、導けない結論を証明として表示しない設計にします。

## 次の開発ステップ

1. ルールと前提条件をデータとして分離する
2. 推論の各段階を検査する小さな検証器を追加する
3. 2017〜2026年の問題データに合わせて、対応するパターンを段階的に増やす
4. 各ルールにテストを用意し、誤った証明が出ないことを確認する
