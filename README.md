# 証明問題メーカー

中学図形の証明を、理由と手順を確認しながら学ぶためのブラウザアプリです。

## 現在できること

- 二等辺三角形の底角、平行線の錯角・同位角、直径に対する円周角、相似・合同条件など、登録済みの規則で証明できるかを確認する。
- 前提から結論までの推論ステップ、使った定理ID、理由文を記録する。
- 登録済みの問題テンプレートから、証明ルールで結論を確認できた問題を選んで表示する。
- 定理カタログ（`js/theorem-catalog.js`）の一意なID・名称・理由文を証明エンジン（`js/proof-rules.js`）と共有する。
- 正例・負例テストを使って、前提が不足しているときに誤った結論を出さないことを検査する。

## 現在できないこと・注意点

- 任意の図形や条件から、問題文・図・証明を自由に自動生成すること。
- 図の画像を読み取り、点・直線・円・交点・平行関係などを自動認識すること。
- 登録されていない定理を使うことや、どんな証明でも必ず見つけること。
- 定理カタログの型付き前提・結論をすべて汎用的に照合して推論すること。現在は個別に実装した文字列ベースの規則も使う。
- 図の見た目だけから数学的な条件を推測すること。

この仕組みは登録済みルールの範囲内で動く初期エンジンであり、一般的な幾何学の証明器ではありません。証明できない場合は、ルール不足または前提不足として失敗を返します。各問題の条件が実際に正しいか、原問題と照合する作業も引き続き必要です。

## 起動方法

`index.html` をブラウザで開きます。ビルドツールやサーバーは不要です。

## 主なファイル

- `js/theorem-catalog.js`: 定理ID、型付き前提・結論、理由文、正例・負例の仕様
- `js/proof-rules.js`: 登録済みの推論ルールと証明探索
- `js/geometry-relations.js`: 明示された点の順序から同じ向き・反対向きの半直線と対頂角を導く層
- `js/problem-data-engine.js`: 専用問題データを既存の事実形式へ変換し、推論を実行するアダプター（未対応条件は明示）
- `js/problem-generator.js`: 登録済みテンプレートを証明ルールで検査して選ぶ処理
- `js/app.js`: 問題表示と証明ステップの描画
- `tests/proof-rules.test.js`: 証明ルールの正例・負例テスト
- `tests/theorem-catalog.test.js`: カタログ構造と実行時ID接続のテスト
- `docs/geometry-theorem-catalog.md`: 定理カタログの仕様と未実装範囲

## 問題データ形式（初版）

- `docs/problem-data-format.md`: 専用形式 v1 の仕様
- `docs/point-order-and-angle-normalization.md`: 同一直線上の点の順序、半直線、角の言い換えの扱い
- `data/problem-examples/shizuoka-2025-proof-7-1.json`: 2025年度の入試問題を構造化した例（証明そのものは未検証）
- `tests/problem-data-format.test.js`: JSON構造と参照IDの基本検査
- `tests/problem-data-engine.test.js`: 変換、表記ゆれの正規化、証明エンジン接続のテスト

## 次の開発ステップ

1. 交点・平行線・円周角などの幾何条件を、根拠のある事実へ安全に変換する範囲を増やす
2. 円・弧・交点・点の位置関係などの事実表現をさらに厳密にする（特に点の順序は明示条件からのみ導く）
3. 2017〜2026年の問題データに合わせて、問題型と推論ルールを追加する
4. 各ルールの正例・負例テストを増やし、過去問を使って適用の妥当性を確認する
